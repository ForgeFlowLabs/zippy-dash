# Quality Guidelines (Guideline — not mandatory, but recommended)

This page describes a number of guidelines to publish a successful game on the CrazyGames platform. The guidelines should be used alongside the mandatory requirements.

## Onboarding
- Provide a simple onboarding phase where new users land directly.
- Implement the onboarding in gameplay.
- Focus on core functionality so users can start playing; avoid explaining every feature.
- Make the onboarding phase skippable.
- Prioritize visuals, limit text.
- Show controls via keyboard overlay or mouse gestures (see Restricted Keys).
- UI must be clear: buttons clearly labeled, not sized to encourage ads/other behaviors, no artificial delays.

## General principles
- Clear goals the player can reach.
- Easy to learn.
- Easy to understand — correct/clear language, or good universal graphics prompts.
- Consistent, intuitive controls throughout.

## What makes a game fun
- Responds quickly to player actions.
- Balanced, well-paced challenge/strategy/story.
- Comfortable, intuitive display layout.
- Comfortable, appropriate audio.
- Interface designed for the user's device (desktop, optionally mobile).
- Appeals to various player segments.
- Interesting story/scenarios where applicable.
- No overly repetitive/boring tasks.
- Smooth flow and continuity (fast information processing).
- Solo play should be as prominent as multiplayer if both are offered; if solo isn't available, say so clearly.

## Uniqueness
- Easy to improve/modify (new levels, art, story).
- Major features (genre) shouldn't change after submission.
- Should be frequently maintained/updated.
- Not easily confused with another game of similar name/iconography.
- Does not use a common identifier unless the developer owns that IP.
  - Example: "Super Chess" is fine; plain "Chess" is not.
  - "Scrabble" can only be used by the IP holder.

## Aesthetics
- High-quality, high-resolution graphics; consistent resolution throughout; no compression artifacts.
- Audio: consistent levels, not too loud/quiet, music complements the visuals.
- Internally consistent art style (no switching photorealistic ↔ cartoony, or high-res ↔ low-res).
- The game must clearly represent what it is — name/imagery on CrazyGames should accurately reflect genre/type. Only change name/imagery when a real update/overhaul happens.

## Restricted Keys
- Controls should be intuitive and easy to learn.
- Prefer adapting key bindings to the user's keyboard layout rather than requiring them to remap.
  - Note: France uses AZERTY, where WASD becomes ZQSD.
- Avoid keys with special browser behavior:
  - Escape closes fullscreen.
  - Ctrl/Cmd+W closes the tab (can disable while in fullscreen).
